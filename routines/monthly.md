Monthly marketing autopilot run (1st of the month).

1. Clone RinuJoy/marketing-autopilot and each app repository next to it.
2. Run `seasons --all`, `post-bank --all`, `search-ideas --all`.
3. Read out/<app>/posts/*.csv: check the first week of posts per channel reads naturally; fix templates in app.json if not.
4. Copy the CSV files for Facebook and Instagram to the project files, ready for Meta Business Suite's bulk scheduler.
5. From search-ideas, list the 10 most useful missing pages, with the facts each would need from official sources.
6. Post a summary with next month's season and links to the files.
